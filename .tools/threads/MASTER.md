# PROJECT THREADS VIRAL — 대한민국 생활 꿀팁 수익화 (사장님 지시, 2026-11-28)
스레드 글은 이 문서 + .content-guide.md 스레드 절을 함께 따른다. (원문 요약본 — 핵심 규칙)

- 역할: 조회·공유·댓글·저장·프로필 방문·링크 클릭을 만드는 콘텐츠 전략가. 정보 나열 금지.
- 분야: A 생활비 절약(공과금·통신비·구독료·할인·지원금) / B 생활 속 숨은 꿀팁(청소·세탁·주방·보관·시간 절약·폰 기능) / C 제품·소비 꿀팁(가성비·활용법·비교·구매 전 확인·소비 줄이기) / D 놓치는 정보(제도·소비자 권리·환불·공공서비스·잘못 아는 상식). 뻔한 상식 금지, 바로 써먹는 구체 정보만.
- 첫 문장: 손실 회피·호기심·공감·반전·긴급성·실용성·자기 관련성. 평범한 설명으로 시작 금지. 예시 문장 반복 금지, 매번 새 표현. 사실 왜곡·공포 조장 금지.
- 구조(주제별로 골라 씀, 매번 같은 구조 금지): 1 손해 방지형 / 2 꿀팁 공개형 / 3 공감 유도형 / 4 제품 추천형(단점·주의점 포함 + 자연스러운 링크) / 5 정보 반전형.
- 문체: 실제 사람처럼, 광고체·전문용어·서론·결론 반복·이모지 남발 금지. 짧은 문장, 친구에게 알려주듯. 같은 말투·표현 반복 금지. 과장된 성공담·억지 감동 금지.
- 링크: 모든 글에 넣지 않음. 제품 글 = 제휴 링크(본문에서 추천 이유 충분히, 가격·특징 확인, 단점 포함, 가짜 후기 금지, 수수료 표시). 심층 정보 = 자체 웹사이트(스레드에서 핵심은 충분히 주고 비교표·상세는 사이트). 정보 글은 링크 없이 완결. 링크의 가치를 설명. 실제 연결되는 URL만.
- 차별화: 매일 비효율적으로 하는 행동, 더 싸게 해결할 수 있는 일, 몰라서 손해 보는 정보, 새 제품으로 해결되는 불편, 더 간단한 해결책. 가족·자취생·직장인·주부 공감 상황.
- 검증: 지원금·법·소비자 권리·금융·통신 요금·가격·정책·건강·안전은 최신 공식 자료 필수. 확인 못 한 경험·통계·후기·가격 창작 금지. 공식 기관·제조사·서비스 제공자 우선.
- 반복 방지: 최근 주제·첫 문장·문장 구조·마무리·제품·링크 중복 관리(.drafts/threads/ 기록 확인). 정보형·공감형·절약형·제품형·반전형을 섞는다.
- 출력 형식: [콘텐츠 주제] [콘텐츠 유형] [후킹] [최종 게시물] [댓글 유도 문장] [링크 전략] [링크 삽입 위치] [근거 및 출처]
- 자기 점검 7문항: 첫 문장에서 멈출 이유? 끝까지 읽을 정보? 실생활 도움? 공유 가치? 차별화? 광고 아닌 정보로 느껴지나? 링크 클릭할 합리적 이유? → 미달이면 다시 쓴다.
- 목표: 조회수 → 관심 → 신뢰 → 팔로우 → 링크 클릭 → 구매/방문. 가장 중요한 건 신뢰.
- 사장님 비선호: 무 주제, 밋밋한 청소·보관 요령 나열, 광고 같은 '숨은 돈' 류, 통신비·요금제 류(영업 같음).
- 형식(사장님 확인): 본문은 후킹 1~3줄 + 👇 로 끝내고, 내용은 본인 댓글 3~5개로 번호 매겨 이어 쓴다(replies). 마지막 댓글에 질문. 링크는 해당 댓글에.

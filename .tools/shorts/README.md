# 쇼츠 템플릿 (2026-11-27 사장님 확정: 나레이션 없음)

- 세로 1080×1920, 15~19초, 장면당 1.5~2.5초 빠른 컷
- 첫 1초 훅: 짧은 명령·경고형 문장 3덩어리 ("김치냉장고 / 설정 / 꼭 확인하세요"), 마지막 덩어리 빨간색 + 흔들림. 사실보다 과장 금지
- 자막: 박스·알약·둥근 상자 없이 굵은 흰 글씨 + 두꺼운 검은 외곽선, 강조어만 노란색 (#ffe033), 빨강은 경고 1곳만
- 정답·목록은 "항목 → 값" 한 줄씩 옆에서 날아 들어오기
- 마지막: "저장 해두세요" + "자세한 건 블로그에"
- 배경: Pixabay 영상(키: 스크래치패드 .pixabay_key, /api/videos/), 첫 장면만 확대→축소 펀치, 장면 전환 순간 짧은 흰 플래시, 상단 노란 진행 막대
- 소리: 나레이션 없음, 무음 트랙만. 배경음악은 사장님이 업로드할 때 앱에서 선택
- 만드는 법: captions-kimchi-example.js 의 SCENES·TOTAL 을 글 내용에 맞게 바꿔 투명 PNG 프레임 렌더 → 배경 영상 컷 이어 붙이기 → ffmpeg overlay + 진행 막대

## 자동 제작 (2026-11-27 추가)
- `python3 .tools/shorts/make-short.py spec.json 작업폴더 출력.mp4` 한 줄로 배경 컷 → 자막 프레임(kinetic.js) → 합성 → 확인용 sheet.png 까지
- spec: `{total, tag, scenes:[...], segs:[{video,ss,d,punch}|{image,d}]}` (segs 길이 합 = total, 영상 길이보다 ss+d 가 길면 영상이 짧아지니 확인)
- 제품 주제는 마지막 장면에 `arrow` (네이버 클립 왼쪽 아래 상품 칩 쪽), 정보 주제는 "저장 해두세요 / 자세한 건 블로그에"

## 훅 규칙 v2 (2026-11-28 사장님 지시: 후킹 더 강하게)
- 0.5초 안에 훅 3줄이 전부 화면에 떠 있게 (at 0.0 / 0.2 / 0.45). 핵심 단어가 1초 뒤에 나오면 이미 넘김
- 명령형("확인하세요")보다 세 가지 틀 중 하나: ① 오해 깨기 "~할 수 있다? → 못 해요" ② 결과 예고 "~하면 생기는 일 → 결과" ③ 숨긴 정보 "이 글자 있는 ○○는 → 하지 마세요"(2장면에서 정답 공개)
- 마지막 줄은 빨강+흔들림, 사실 범위 안에서만 (과장·공포 조장 금지)
- 썸네일 (2026-11-28): 첫 장면 훅 3줄은 0초부터 완성된 모습으로 보이게 함(instantHook, 기본 켬) → 영상 첫 프레임이 곧 표지. make-short.py 가 `<이름>_표지.jpg` 도 같이 만듦. 네이버 클립 업로드 때 커버를 첫 장면(0초)으로 고르거나 표지 jpg 를 올린다. 글자는 화면 세로 가운데(위아래 25% 여백 안)에 둬서 피드에서 잘려도 보이게

## 나레이션 (Typecast API, 2026-11-28 연동)
- `narration.py`: 장면에 `"say": "읽을 문장"` 을 넣으면 make-short.py 가 자동으로 Typecast 음성 트랙(narration.m4a)을 만들어 깐다. say 가 없으면 예전처럼 무음
- 목소리 고르기: `python3 .tools/shorts/narration.py voices "원하는 목소리 설명"` → typecast.json 의 voice_id 에 넣기
- 크레딧 확인: `python3 .tools/shorts/narration.py sub`
- 키는 코드·파일에 두지 않는다 (세션 네트워크 비밀 또는 TYPECAST_API_KEY). 수익 영상은 유료 API 요금제(Lite 이상)로 만든 음성만 사용
- 장면 길이보다 말이 길면 속도를 최대 1.3배까지 올려 맞추고, 그래도 길면 경고 → 문장을 줄인다

## EXTREME HOOK 시스템 (2026-11-28 사장님 제공 — 모든 쇼츠에 적용)
- 주제마다: 후킹 30개 → 100점 평가(스크롤 정지 30, 호기심 20, 관련성 15, 감정 15, 본문 연결 10, 차별성 10) → 탈락(뻔함·과장·근거 없음·궁금증 없음·다 공개·낚시) → 서로 다른 심리 기법 TOP 5 → 최종 1개 → 그 후킹에 맞춰 대본·장면 설계
- 금지: "안녕하세요/오늘은/여러분" 시작, 평범한 질문, 사실 왜곡. 후킹의 궁금증은 영상 안에서 반드시 해소
- 기록: 주제별 후킹 30개와 점수는 .drafts/hooks/ 에 남긴다
- 채널 역할(2026-11-28): 부자되는1000가지방법 = 혜택·지원금(목소리 서진), 엠지픽 = 생활·제품 호기심, 네이버 클립 = 상품 정보(쇼핑커넥트)

## 배경음악 (2026-11-28) — 직접 합성, 저작권 걱정 없음
- `bgm.py <upbeat|calm|curious|urgent> <길이> <출력.wav> [시드]` : 코드로 만든 우리 음악(외부 음원 없음). 시드(영상 이름)마다 멜로디가 달라짐
- spec 에 `"bgm": "calm"` 을 넣으면 make-short.py 가 자동으로 깔고, 나레이션이 나올 때 음악을 낮춤(덕킹)
- 외부 음악 API(Freesound CC0, Mubert 등)를 연결하면 그때 교체 가능
- (갱신) 배경음악 기본 = Freesound CC0 보관함 `.music/<분위기>/` (music_library.py fill 로 채움, 곡 정보 .music/index.json). 직접 합성 bgm.py 는 사장님 평가로 기본에서 제외
